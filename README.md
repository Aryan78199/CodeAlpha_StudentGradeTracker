# Student Grade Tracker

A Java-based Student Grade Tracker application designed to manage student information and calculate academic grades efficiently.

## 📌 Project Overview

The Student Grade Tracker is a simple Java application that allows users to store student details, manage marks, and calculate grades based on their performance.

This project was developed as part of my CodeAlpha Java Development Internship to strengthen my understanding of Java programming and Object-Oriented Programming concepts.

## 🚀 Features

- Add student details
- Store student marks
- Calculate total marks
- Calculate percentage
- Assign grades based on performance
- Display student information
- Simple and easy-to-use Java application

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Classes and Objects
- Conditional Statements
- Methods
- Arrays / Data Handling
